- [x] **Security fix: Stripe webhook signature bypass (2026-07-31, dev-loop iteration 7)**: `src/pages/api/webhooks/stripe.ts` decided whether to skip Stripe signature verification via `request.url.includes('localhost')` — a substring match against the *entire* incoming URL, including the query string. In production, a request like `POST /api/webhooks/stripe?x=localhost` would satisfy that check, causing the handler to `JSON.parse` the raw body directly as a trusted `Stripe.Event` instead of verifying it via `stripe.webhooks.constructEvent`. Fixed to check the actual parsed hostname (`new URL(request.url).hostname`), which is immune to query-string manipulation, and to accept both `localhost` and `127.0.0.1` for local-dev robustness (the latter is what some `stripe listen --forward-to` setups use by default).
